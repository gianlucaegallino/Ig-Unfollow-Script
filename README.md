# Instagram Unfollower Script 🚫👥

This script automates the process of **unfollowing users on Instagram** using PyAutoGUI.  
It simulates human-like interactions to help you clean up your following list without manually clicking through profiles.

---

## ⚡ Features
- Automates the unfollowing process
- Works directly in your browser (via GUI automation)
- Runs on **Python 3.11.10** 🐍
- Simple and lightweight

---

## 📦 Requirements
- Python **3.11.10**
- [PyAutoGUI](https://pypi.org/project/PyAutoGUI/)  
- Other dependencies (see `requirements.txt`)

---

## 🔧 Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/yourusername/instagram-unfollower.git
cd instagram-unfollower
pip install -r requirements.txt
```
